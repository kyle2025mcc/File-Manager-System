# File Manager System
Tool to help manage files developed in python. Currently has three functions finding folders/files that contain a certain keyword, finding all files above a certain size, and swapping/moving the contents between two folders. User can select the scope of the file navigator by indicating what path they want the script to access.
To download go to the dist directory and download the zip file. The script is safe to download and will only affect files that the user tells it to. So far only works for window operating systems.
